# EMDR Trainer

### Free EMDR tool for specialists and their clients

Entraineur de stimulation bilaterale pour l'ancrage, le ressourcement et la relaxation.<br/>
Avec un mode session pilote par le specialiste, une base scientifique honnete et la prise en charge de 7 langues.

> Ceci est un outil d'auto-assistance, et non un substitut a une psychotherapie. Le retraitement complet du traumatisme est mene par un therapeute EMDR certifie. L'outil aide a l'etape de stabilisation et comme soutien entre les seances.

<br/>

## Fonctionnalites

<table>
<tr>
<td width="50%" valign="top">

### Session avec un specialiste
Le therapeute cree une session et envoie un lien au client. Le client voit un ecran epure avec uniquement la stimulation, sans reglages. Le specialiste lance et arrete la stimulation, change les modes, et tout se met a jour de maniere synchrone chez le client. Le bouton d'ancrage reste toujours accessible chez le client.

</td>
<td width="50%" valign="top">

### Stimulation visuelle
9 motifs de mouvement (horizontale, verticale, diagonales, lemniscate, points, pulsation, colonnes, zigzag), suivi fluide ou saccades, reglage de la vitesse, de l'amplitude, de la taille, de la forme et de la couleur de la cible.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Son et fonds sonores
Stimulus bilateral (tonalite douce, clics, metronome, bruit blanc, rythmes binauraux) et 10 fonds sonores proceduraux : pluie, vagues, vent, respiration, bruit rose et brun, drone et autres. Tout est genere dans le navigateur, sans fichiers externes. Un mode silencieux est disponible.

</td>
<td width="50%" valign="top">

### Charge cognitive
Un flux optionnel de symboles sur la cible, qui sollicite la memoire de travail, avec choix de l'alphabet. La vitesse et l'intensite se reglent selon le client.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Securite
Consentement eclaire et court depistage des contre-indications avant le demarrage, bouton permanent "Stop et ancrage" avec la technique 5-4-3-2-1 et la respiration carree, mode de reduction du mouvement pour les personnes photosensibles.

</td>
<td width="50%" valign="top">

### Base scientifique
Guide integre avec une evaluation honnete de l'efficacite par trouble et des liens vers les sources : OMS, NICE, ISTSS, APA, Cochrane. Sans surestimation et sans promesses de guerison.

</td>
</tr>
</table>

## Demarrage rapide

```bash
npm install
npm run dev
```

Ouvrez http://localhost:3000

Production :

```bash
npm run build
npm start
```

### Docker

```bash
docker compose up -d --build
```

## Retour d'experience dans l'application (optionnel)

Le formulaire de retour d'experience peut envoyer des messages vers Telegram. Sans configuration, il se contente de recevoir la saisie et n'envoie rien. Pour activer la livraison :

```bash
TELEGRAM_TOKEN=...
TELEGRAM_CHAT_ID=...
```
