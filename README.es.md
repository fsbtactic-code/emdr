# EMDR Trainer

### Free EMDR tool for specialists and their clients

Entrenador de estimulacion bilateral para el anclaje, la creacion de recursos y la relajacion.<br/>
Con modo de sesion dirigida por el especialista, una base de evidencia honesta y soporte para 7 idiomas.

> Esta es una herramienta de autoayuda, no un sustituto de la psicoterapia. El procesamiento completo del trauma lo lleva a cabo un terapeuta EMDR certificado. El entrenador ayuda en la fase de estabilizacion y como apoyo entre sesiones.

<br/>

## Funcionalidades

<table>
<tr>
<td width="50%" valign="top">

### Sesion con el especialista
El terapeuta crea una sesion y envia al cliente un enlace. El cliente ve una pantalla limpia solo con la estimulacion, sin ajustes. El especialista inicia y detiene la estimulacion, cambia los modos, y en el cliente todo se actualiza de forma sincronizada. El boton de anclaje del cliente esta siempre disponible.

</td>
<td width="50%" valign="top">

### Estimulacion visual
9 patrones de movimiento (horizontal, vertical, diagonales, lemniscata, puntos, pulso, columnas, zigzag), seguimiento suave o sacadas, ajuste de velocidad, amplitud, tamano, forma y color del objetivo.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Sonido y fondos
Estimulo bilateral (tono suave, clics, metronomo, ruido blanco, ritmos binaurales) y 10 fondos procedurales: lluvia, olas, viento, respiracion, ruido rosa y marron, dron y otros. Todo se genera en el navegador, sin archivos externos. Hay un modo sin sonido.

</td>
<td width="50%" valign="top">

### Carga cognitiva
Flujo opcional de simbolos sobre el objetivo que carga la memoria de trabajo, con eleccion de alfabeto. La velocidad y la intensidad se ajustan a cada cliente.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Seguridad
Consentimiento informado y un breve cribado de contraindicaciones antes de empezar, boton permanente de "Parar y anclar" con la tecnica 5-4-3-2-1 y la respiracion cuadrada, modo de reduccion de movimiento para personas con fotosensibilidad.

</td>
<td width="50%" valign="top">

### Base de evidencia
Guia integrada con una evaluacion honesta de la eficacia por trastornos y enlaces a las fuentes: OMS, NICE, ISTSS, APA, Cochrane. Sin sobrevalorar y sin promesas de curacion.

</td>
</tr>
</table>

## Inicio rapido

```bash
npm install
npm run dev
```

Abre http://localhost:3000

Produccion:

```bash
npm run build
npm start
```

### Docker

```bash
docker compose up -d --build
```

## Comentarios dentro de la aplicacion (opcional)

El formulario de comentarios puede enviar mensajes a Telegram. Sin configuracion, simplemente acepta la entrada y no envia nada. Para activar la entrega:

```bash
TELEGRAM_TOKEN=...
TELEGRAM_CHAT_ID=...
```

## Idiomas

Русский, English, Espanol, Italiano, Deutsch, Francais, Portugues. La seleccion del idioma se hace al inicio y en los ajustes.
