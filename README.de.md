# EMDR Trainer

### Free EMDR tool for specialists and their clients

Trainer fuer bilaterale Stimulation zur Erdung, Ressourcenstaerkung und Entspannung.<br/>
Mit einem Sitzungsmodus unter Anleitung des Spezialisten, einer ehrlichen Evidenzbasis und Unterstuetzung fuer 7 Sprachen.

> Dies ist ein Werkzeug zur Selbsthilfe, kein Ersatz fuer eine Psychotherapie. Die vollstaendige Traumaverarbeitung fuehrt ein zertifizierter EMDR-Therapeut durch. Der Trainer hilft in der Stabilisierungsphase und als Unterstuetzung zwischen den Sitzungen.

<br/>

## Funktionen

<table>
<tr>
<td width="50%" valign="top">

### Sitzung mit dem Spezialisten
Der Therapeut erstellt eine Sitzung und sendet dem Klienten einen Link. Der Klient sieht einen aufgeraeumten Bildschirm nur mit der Stimulation, ohne Einstellungen. Der Spezialist startet und stoppt die Stimulation, wechselt die Modi, und beim Klienten wird alles synchron aktualisiert. Die Erdungsschaltflaeche bleibt beim Klienten immer verfuegbar.

</td>
<td width="50%" valign="top">

### Visuelle Stimulation
9 Bewegungsmuster (Horizontale, Vertikale, Diagonalen, Lemniskate, Punkte, Puls, Saeulen, Zickzack), sanftes Verfolgen oder Sakkaden, Einstellung von Geschwindigkeit, Amplitude, Groesse, Form und Farbe des Ziels.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Klang und Hintergruende
Bilateraler Stimulus (sanfter Ton, Klicks, Metronom, weisses Rauschen, binaurale Beats) und 10 prozedurale Hintergruende: Regen, Wellen, Wind, Atem, rosa und braunes Rauschen, Drone und weitere. Alles wird im Browser erzeugt, ohne externe Dateien. Es gibt einen Modus ohne Ton.

</td>
<td width="50%" valign="top">

### Kognitive Belastung
Ein optionaler Strom von Symbolen auf dem Ziel, der das Arbeitsgedaechtnis belastet, mit Auswahl des Alphabets. Geschwindigkeit und Intensitaet lassen sich auf den Klienten abstimmen.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Sicherheit
Informierte Einwilligung und ein kurzes Screening der Kontraindikationen vor dem Start, eine dauerhaft verfuegbare Schaltflaeche "Stopp und Erdung" mit der 5-4-3-2-1-Technik und der Box-Atmung, ein Modus zur Reduzierung der Bewegung fuer Menschen mit Lichtempfindlichkeit.

</td>
<td width="50%" valign="top">

### Evidenzbasis
Ein integrierter Leitfaden mit einer ehrlichen Einschaetzung der Wirksamkeit nach Stoerungsbildern und mit Verweisen auf Quellen: WHO, NICE, ISTSS, APA, Cochrane. Ohne Ueberbewertung und ohne Heilversprechen.

</td>
</tr>
</table>

## Schnellstart

```bash
npm install
npm run dev
```

Oeffnen Sie http://localhost:3000

Produktion:

```bash
npm run build
npm start
```

### Docker

```bash
docker compose up -d --build
```

## In-App-Feedback (optional)

Das Feedback-Formular kann Nachrichten an Telegram senden. Ohne Konfiguration nimmt es lediglich die Eingabe entgegen und sendet nichts. Um die Zustellung zu aktivieren:

```bash
TELEGRAM_TOKEN=...
TELEGRAM_CHAT_ID=...
```
