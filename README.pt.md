# EMDR Trainer

### Free EMDR tool for specialists and their clients

Treinador de estimulacao bilateral para aterramento, criacao de recursos e relaxamento.<br/>
Com modo de sessao controlada pelo especialista, uma base de evidencias honesta e suporte a 7 idiomas.

> Esta e uma ferramenta de autoajuda, nao um substituto da psicoterapia. O processamento completo do trauma e conduzido por um terapeuta EMDR certificado. O treinador ajuda na fase de estabilizacao e como apoio entre as sessoes.

<br/>

## Recursos

<table>
<tr>
<td width="50%" valign="top">

### Sessao com o especialista
O terapeuta cria uma sessao e envia um link ao cliente. O cliente ve uma tela limpa apenas com a estimulacao, sem configuracoes. O especialista inicia e para a estimulacao, troca os modos, e tudo e atualizado de forma sincronizada para o cliente. O botao de aterramento permanece sempre disponivel para o cliente.

</td>
<td width="50%" valign="top">

### Estimulacao visual
9 padroes de movimento (horizontal, vertical, diagonais, lemniscata, pontos, pulso, colunas, ziguezague), rastreamento suave ou sacadas, ajuste de velocidade, amplitude, tamanho, forma e cor do alvo.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Som e fundos
Estimulo bilateral (tom suave, cliques, metronomo, ruido branco, ritmos binaurais) e 10 fundos procedurais: chuva, ondas, vento, respiracao, ruido rosa e marrom, drone e outros. Tudo e gerado no navegador, sem arquivos externos. Ha um modo sem som.

</td>
<td width="50%" valign="top">

### Carga cognitiva
Um fluxo opcional de simbolos sobre o alvo que sobrecarrega a memoria de trabalho, com escolha de alfabeto. A velocidade e a intensidade sao ajustadas conforme o cliente.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Seguranca
Consentimento informado e uma breve triagem de contraindicacoes antes de comecar, um botao permanente "Parar e aterrar" com a tecnica 5-4-3-2-1 e respiracao quadrada, e um modo de reducao de movimento para pessoas com fotossensibilidade.

</td>
<td width="50%" valign="top">

### Base de evidencias
Guia integrado com uma avaliacao honesta da eficacia por condicao e links para as fontes: OMS, NICE, ISTSS, APA, Cochrane. Sem superestimar e sem promessas de cura.

</td>
</tr>
</table>

## Inicio rapido

```bash
npm install
npm run dev
```

Abra http://localhost:3000

Producao:

```bash
npm run build
npm start
```

### Docker

```bash
docker compose up -d --build
```

## Feedback no aplicativo (opcional)

O formulario de feedback pode enviar mensagens para o Telegram. Sem configuracao, ele apenas recebe a entrada e nao envia nada. Para ativar a entrega:

```bash
TELEGRAM_TOKEN=...
TELEGRAM_CHAT_ID=...
```
