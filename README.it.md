# EMDR Trainer

### Free EMDR tool for specialists and their clients

Strumento di stimolazione bilaterale per il grounding, il rafforzamento delle risorse e il rilassamento.<br/>
Con una modalita sessione gestita dallo specialista, una base scientifica onesta e il supporto di 7 lingue.

> Questo e uno strumento di auto-aiuto, non un sostituto della psicoterapia. La rielaborazione completa del trauma viene condotta da un terapeuta EMDR certificato. Lo strumento aiuta nella fase di stabilizzazione e come supporto tra una sessione e l'altra.

<br/>

## Funzionalita

<table>
<tr>
<td width="50%" valign="top">

### Sessione con lo specialista
Il terapeuta crea una sessione e invia al cliente un link. Il cliente vede una schermata pulita con la sola stimolazione, senza impostazioni. Lo specialista avvia e ferma la stimolazione, cambia le modalita, e dal lato del cliente tutto si aggiorna in modo sincronizzato. Il pulsante di grounding del cliente resta sempre disponibile.

</td>
<td width="50%" valign="top">

### Stimolazione visiva
9 pattern di movimento (orizzontale, verticale, diagonali, lemniscata, punti, pulsazione, colonne, zigzag), inseguimento fluido o saccadi, regolazione di velocita, ampiezza, dimensione, forma e colore del bersaglio.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Suono e sfondi
Stimolo bilaterale (tono morbido, click, metronomo, rumore bianco, ritmi binaurali) e 10 sfondi procedurali: pioggia, onde, vento, respiro, rumore rosa e marrone, drone e altri. Tutto viene generato nel browser, senza file esterni. C'e anche una modalita senza suono.

</td>
<td width="50%" valign="top">

### Carico cognitivo
Un flusso opzionale di simboli sul bersaglio, che mette sotto sforzo la memoria di lavoro, con scelta dell'alfabeto. Velocita e intensita si regolano in base al cliente.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### Sicurezza
Consenso informato e un breve screening delle controindicazioni prima di iniziare, un pulsante permanente "Stop e grounding" con la tecnica 5-4-3-2-1 e la respirazione quadrata, una modalita di riduzione del movimento per le persone con fotosensibilita.

</td>
<td width="50%" valign="top">

### Base scientifica
Una guida integrata con una valutazione onesta dell'efficacia per condizione e con riferimenti alle fonti: OMS, NICE, ISTSS, APA, Cochrane. Senza sopravvalutazioni e senza promesse di guarigione.

</td>
</tr>
</table>

## Avvio rapido

```bash
npm install
npm run dev
```

Apri http://localhost:3000

Produzione:

```bash
npm run build
npm start
```

### Docker

```bash
docker compose up -d --build
```

## Feedback nell'app (opzionale)

Il modulo di feedback puo inviare i messaggi a Telegram. Senza configurazione, si limita ad accettare l'input e non invia nulla. Per abilitare la consegna:

```bash
TELEGRAM_TOKEN=...
TELEGRAM_CHAT_ID=...
```
