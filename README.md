# EMDR Trainer

**Free EMDR tool for specialists and their clients.**

Тренажер билатеральной стимуляции для заземления, ресурсирования и релаксации. С режимом сессии под управлением специалиста, честной доказательной базой и поддержкой 7 языков.

## Что это

Веб-инструмент билатеральной стимуляции (визуальной, звуковой и тактильной по ощущению) для самопомощи и для работы в паре со специалистом. Подходит для отработки навыков стабилизации: безопасное место, заземление, дыхание, ресурсирование.

Это не замена психотерапии. Полноценную переработку травмы ведет сертифицированный EMDR-терапевт; инструмент помогает на этапе стабилизации и как фон между сессиями.

## Возможности для специалистов

- **Сессия под управлением специалиста.** Терапевт создает сессию, отправляет клиенту ссылку. Клиент видит чистый экран только со стимуляцией: без настроек и кнопок. Специалист со своей стороны запускает и останавливает стимуляцию, меняет режимы, а у клиента все обновляется синхронно. Кнопка заземления у клиента остается всегда.
- **Визуальная стимуляция.** 9 паттернов движения (горизонталь, вертикаль, диагонали, лемниската, точки, пульс, столбы, зигзаг), плавное слежение или саккады, регулировка скорости, размаха, размера, формы и цвета мишени.
- **Когнитивная нагрузка.** Опциональный поток символов на мишени (нагрузка на рабочую память) с выбором алфавита.
- **Звук.** Билатеральный стимул (мягкий тон, щелчки, метроном, белый шум, бинауральные ритмы) и 10 процедурных фонов (дождь, волны, ветер, дыхание, розовый и коричневый шум, дрон и другие). Все фоны генерируются в браузере, без внешних файлов. Есть режим без звука.
- **Безопасность.** Информированное согласие и короткий скрининг противопоказаний перед стартом, постоянная кнопка "Стоп и заземление" с техникой 5-4-3-2-1 и квадратным дыханием, режим снижения движения для людей с фоточувствительностью.
- **Доказательная база.** Встроенное руководство с честной оценкой эффективности по состояниям и ссылками на источники (ВОЗ, NICE, ISTSS, APA, Cochrane).
- **Пресеты и шеринг.** Готовые наборы параметров и ссылка для передачи конфигурации.
- **7 языков:** русский, английский, испанский, итальянский, немецкий, французский, португальский. Выбор языка на старте и в настройках.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

Сборка и продакшен:

```bash
npm run build
npm start
```

### Docker

```bash
docker compose up -d --build
```

## Обратная связь в приложении (опционально)

Форма обратной связи может отправлять сообщения в Telegram. Без настройки она просто принимает ввод и ничего не отправляет. Чтобы включить доставку, задайте переменные окружения:

```
TELEGRAM_TOKEN=...
TELEGRAM_CHAT_ID=...
```
